# Engagement Context

Fill this in after the outcome statement has passed `/outcome` and before Phase 0.
It is the main source of project-specific facts. Leave an answer as `unknown`
rather than guessing: unknowns become tracked open questions, guesses become
errors nobody can find later.

Claude Code reads this file and cannot edit it.

## Mode

Pick one and delete the other.

- `CLIENT`: a real organisation. Numbers and commitments are never assumed.
- `REFERENCE`: a reference or demonstration design for a fictional organisation.
  Illustrative values are allowed, each logged as an assumption.
